# Assets

Everything in `logos/` is a **placeholder**. Replace with the official files from Fenix
and Cegid PartnerSpace, keeping the same file names so no code changes are needed.

| File | What it should be |
| --- | --- |
| `logos/fenix-wordmark.svg` | Fenix text logo, colour version (light backgrounds) |
| `logos/fenix-wordmark-inverse.svg` | Fenix text logo, white version (dark backgrounds) |
| `logos/fenix-mark.svg` | Fenix square logo (navbar collapsed state) |
| `logos/cegid-partner-bronze.svg` | Official Cegid Partner Bronze badge (then set `partnerBadge.image` in `content/pt/common.js`) |

`images/`: hero and section photos as `.webp` (~1600px wide max). Check the licence of
every image (Canva Free / Unsplash / Pexels) and note its source in `images/SOURCES.md`.

`icons/`: custom icons, if the designer provides them. Until then, `ui/Icon` maps names to
lucide-react icons.
